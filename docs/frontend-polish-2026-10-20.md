# 前端显示优化与验收记录

## 目标与设计

面向通过简历进入的面试官和技术读者，优先展示定位、可验证的项目和实现文章。
保留原有项目、内容数据与 URL。仓库声明的 `skills-src/` 不存在，因此按实际代码、
PRODUCT.md 和已安装的 design-taste-frontend 技能完成设计与检查。

抽取方向：**Type and nothing else**，seed **1637983323**。保留浅色品牌和墨绿主色，
不重抽。原方向中的无导航和大型空白构图不适合多页技术站，保留全站导航并压缩空白；
示例作品数量也不适合大段作品名称，改为真实项目档案和截图。这些是内容与既有导航的
适配，并未增加虚构项目、客户、评价或统计。

概念：Vie 的技术决策记录成为页面的主标题、项目证据、文章阅读路径与工具入口。
可交互的主体是实际产品截图切换：缩略图、上一张/下一张、键盘切换和原图链接。

## 改动

- 首页：移除通用编程桌面装饰和大图标文章封面；突出定位，以真实项目截图、文章列表、
  浏览器工具和墨绿结尾构成不同的版式。内容数量仍来自实际数据。
- 全局：统一字体、墨色/次级文字、浅色底、焦点与表面层级，减少阴影；修复中等宽度导航
  挤压，补齐系列入口与 GitHub 标签，完善手机菜单关闭和焦点行为。
- 文章/系列：搜索与分类组合筛选，结果数量、空状态复位、整卡系列入口、阅读顺序和
  前后篇触控区域；改善正文、长标题、代码、表格和链接换行。
- 项目：截图数量与原图入口，图库实例唯一 ID，日志永久链接；修复筛选后跳到隐藏日志
  的时序问题，手机目录跳转自动收起，固定筛选栏避让目标记录。
- 工具：移动端字号/布局、错误关联、复制失败反馈、JSON/JWT 快捷键、JWT 标签键盘操作；
  取消时区列表截断，挂载后加载完整选项以保持首屏 SSR 一致。编辑输入后清空旧结果。
  JSON 主操作移到输入区上方，手机不需要先滚过空输出区。
- 数据：文章和系列 loader 加入正文源；正文直接读取同源阅读时长，消除“全部 1 分钟”
  及系列索引/详情总时长不一致。相关说明文章同步更新。
- 搜索：补入由 Layout 渲染、原来没有进入索引的文章标题和摘要；搜索结果显示文章与章节
  上下文，全文标题命中跳到实际标题锚点。添加三个回归测试。
- 动效：入场过程中保留文本可见性，防止节流环境中的空白首屏；继续尊重减少动态效果。

## 浏览器验收

使用实际浏览器、同源 iframe 的真实视口（不是 CSS 缩小页面）检查 **390、768、1440px**。
桌面整体构图另外在实际 1440px iframe 中检查，以缩放预览显示完整布局。
临时检查页已从源码删除，不随构建发布。

检查首页、文章索引、项目列表、Erpilot 详情、系列索引、一篇长技术正文，以及 JSON、
时间戳、JWT 三个工具页。各视口均为一个 H1，未发现页面横向溢出；代码、表格、分类条
和工具切换条允许各自容器内部滚动。截图、文章排版和工具输入在手机布局中人工复核。

行为实测包括：分类与关键词组合/无结果复位，项目截图切换，日志筛选后目录跳转，
JSON 格式化/错误/快捷键，JWT 本地样例与标签方向键，390px 时间戳转换与结果排版，
全局搜索 DTO 返回文章标题及章节上下文。

技能自带的 `inspect.mjs` 两次在本机浏览器启动阶段退出（code 0），因此未取得它的完整
自动测量报告。使用 IAB 实际截图和同源视口检查补充验证，不将其声称为 inspector 通过。
首页组件及新增首页/全局样式的 source lint 为 0 FAIL / 0 WARN；`box-shadow: none` 的
误报及真正悬浮菜单的阴影均在源码中注明理由。

## 视觉复核

ROUND 1

Seen in one second: 通用编程桌面插画和四块数量卡片。

Idea: 真实工程内容被重复卡片和装饰图削弱。

Live thing: 原有项目截图不在首页中展示。

Layout words by section: hero=split / counts=cards / articles=cards / tools=cards。

Scores: design 6.2 · usability 6.8 · creativity 5.5 · content 7.5 → overall 6.4。

Caps applied: 装饰渐变和静态阴影，真实项目图像未充分展示。

Top three problems:

1. 基线首页：首屏插画无法证明项目能力。改为技术定位与真实项目图库。
2. 基线首页：多组相同卡片令层级接近。改为大字、分栏、文章行、工具列表和深色结尾。
3. 基线及内容页：小字偏淡、触控与长文本边界不足。统一墨色、字号、44px 控件与局部滚动。

ROUND 2

Seen in one second: “写清楚每一个技术决策”。

Idea: 从技术主张进入产品证据，再沿着文章和系列解释实现。

Live thing: 首页可切换的真实项目截图，明确的原图与项目档案入口。

Layout words by section: hero=statement / work=split-gallery / articles=rows / tools=split-list / footer=colour-field。

Scores: design 7.6 · usability 8.2 · creativity 7.0 · content 8.4 → overall 7.8。

Caps applied: 未取得完整 inspector 报告；保留现有内容页的品牌芯片、表单边界和代码惯例，
不作为完全符合该技能所有营销页规则的认证。

Top three problems addressed after render:

1. 手机首页主按钮继承了链接墨色：加具体选择器，实际测得白字配 `#0B6547`。
2. 大字结尾被 VitePress 段落行高覆盖：加强段落选择器并复核，不再相互叠压。
3. 手机 JSON 操作在输出区之后：移到工作台顶部，避免不必要的往返滚动。

Remaining: 这是以长篇技术阅读为主的作品集，保留了内容页的实用密度；未进行真实低端
手机、屏幕阅读器全流程或所有浏览器的矩阵测试。
