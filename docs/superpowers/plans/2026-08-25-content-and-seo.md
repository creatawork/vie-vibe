# 个人网站阶段三：种子内容与 SEO 运营 计划

> 本阶段以内容创作和手动操作为主，技术改动极少。无代码任务，按清单执行。

**Goal:** 上线 2~3 篇有深度的种子文章，接入搜索引擎站长平台，形成可持续的更新节奏。

**前置状态：** 阶段一、二已完成，网站可正常访问，统计链路工作。

---

### Task 1: 种子文章（2~3 篇）

从"个人网站开发实录"系列写起——素材现成，且是对自己技术的复盘：

- [ ] **《这个网站是怎么搭起来的》**（完善阶段一留下的示例文章）：选型理由（为什么是 VitePress 而不是 Vue SPA——SEO）、URL 结构设计、CI/CD 流水线。
- [ ] **《给个人网站做访问量统计》**：表结构设计、每日盐 IP 哈希的隐私取舍、UV 口径的选择、防刷策略。
- [ ] 第三篇任选一个有真实踩坑的技术主题：实现细节 + 思路 + 样例代码。

写作规范（对应冻结的 frontmatter）：
- slug 英文小写连字符不含日期；`description` 一句话写清读者收益（它是搜索结果里的摘要）。
- 每篇至少一张 Mermaid 图；代码块标注语言。
- 草稿用 `draft: true` 避免半成品被收录。

### Task 2: 搜索引擎接入

- [ ] 注册并验证 [Google Search Console](https://search.google.com/search-console)，提交 `https://<域名>/sitemap.xml`。
- [ ] 注册并验证 [百度搜索资源平台](https://ziyuan.baidu.com)，提交 sitemap；开启"普通收录"推送或手动提交首页。
- [ ] 一周后检查收录：`site:<域名>`。

### Task 3: 社交入口与外部引流

- [ ] `config.mts` 的 `socialLinks` 补全真实 GitHub；如需知乎/公众号，在"关于"性质的文章末尾或首页自定义区块挂入口。
- [ ] 把 1~2 篇文章同步到知乎/掘金，文末链回本站原文（ canonical 引流，提升主站权重）。

### Task 4: 节奏固化

- [ ] 定下更新节奏：每月 ≥ 1 篇，写进日历提醒。
- [ ] 每月看一次 `/stats-view` 与 Search Console：哪些文章有搜索流量，围绕它们写系列后续。

---

## 验收标准

- [ ] 3 篇文章上线且被 Google 收录（百度可能滞后，正常）
- [ ] RSS 阅读器订阅 `/feed.xml` 能正常解析
- [ ] 统计数据里能看到非本人的访问记录
