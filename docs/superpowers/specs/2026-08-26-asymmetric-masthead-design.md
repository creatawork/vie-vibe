# 不对称刊头全站视觉改造

日期：2026-08-26  
状态：已确认  
范围：全站（首页、列表、正文、系列、成果、`/stats-view`）  
前置：`2026-08-25-personal-site-design.md` 的产品与 URL 冻结仍然有效。

## 1. 背景与目标

当前站点是 VitePress 默认 hero + 列表的冷色皮肤：身份（Vie / 冷纸 / 海军蓝）已有，但结构仍是模板堆叠，显得单调。

本次改造**不换视觉世界**，把现有身份做满：

1. 面试官 10 秒内读到定位，并进入文章或成果。
2. 读者在正文页获得舒适、可扫描的阅读结构。
3. 全站一眼仍是个人技术站，不是主题皮肤。

成功标准：桌面首页必现左刊头 + 右内容流；内页刊头随路由变密度；正文目录在左、无第三栏；对比度与减动效达标。

## 2. 明确不做

- 不改 URL、栏目、内容模型、统计 API。
- 不做个人简介页、评论、登录、后台、搜索（已关闭本地搜索，保持关闭）。
- 不做蓝图 / 原理图 / 终端 / 武侠海报等整站伪装。
- 不做渐变字、装饰性网格/噪点、首页卡片墙、01/02 装饰编号、kicker/eyebrow。
- 不把 DESIGN.md 当作施工前的冻结色板手册；本 spec 是施工合同，DESIGN.md 在实现验收后按实装更新。

## 3. 视觉身份（加深）

字标：**Vie**（`V` 为 signal、字重更重；`ie` 为 ink、略小）。顶栏与左刊头同一套 HTML 字标，禁止依赖 `::first-letter`。

| Token | Hex | 用法 |
|---|---|---|
| paper | `#F3F5F7` | 页底 |
| paper-deep | `#E8ECF1` | 软底 |
| mist | `#D5DCE5` | 栏分割、列表线 |
| ink | `#12161C` | 正文 |
| ink-soft | `#3A4250` | 次要文字 |
| mute | `#5C6672` | 元数据 |
| signal | `#1F4E79` | 字标 V、链接、主按钮 |
| ember | `#C45C26` | 仅刊头竖条与焦点，禁止满页使用 |

深色模式镜像同一角色到近黑纸面。展示字体 Sora，正文字体 Noto Sans SC；正文度量 65–75ch。Google Fonts `display=swap` + preconnect。

## 4. 信息架构与布局

薄顶栏：左 Vie，中 首页 / 文章 / 系列 / 成果，右 GitHub。停用 `layout: home` 默认 Hero。

桌面（≥960px）为 **左刊头 + 右主列**，中间 1px mist 竖线。左栏 sticky。

| 路由 | 左栏密度 | 右栏 |
|---|---|---|
| `/` | 完整：Vie、定位句「写清楚每一个技术决策」、按钮「阅读文章」「查看成果」 | 最新文章（最多 5 篇）+ 精选成果（`featured`） |
| `/articles/`、`/series/`、`/projects` | 中：Vie + 定位句，无大按钮 | 现有列表/网格内容 |
| 文章正文、系列内文 | 窄：Vie + 本页目录。用 CSS 隐藏 `.VPDoc .aside`（不改全局 `themeConfig.outline`，以免影响非文档页） | 页眉元数据 + 标题 + 正文 |
| `/stats-view` | 最简：仅 Vie | 口令表单或图表；少装饰 |

视口宽度小于 960px：左栏改为顶栏下方通栏横条，主内容在其下，不并排。

刊头左侧保留 3px 竖条（signal 为主、底部可极淡接入 ember）。纸面允许现有极轻径向色晕，禁止 repeating-linear 网格与 SVG 噪点滤镜。

## 5. 各表面细则

### 5.1 首页右栏

- 「最新文章」：标题左、日期·时长右，细线分隔；悬停整行浅 signal 底。无缩略图、无卡片。
- 区块头一行：左标题、右「全部文章 →」。
- 「精选成果」：仅 `featured`；名称、一句话、标签、GitHub/Demo。项目块允许 12px 圆角与 1px mist 边，悬停轻抬。无 featured 则整块不渲染。

### 5.2 列表

- 文章列表按分类分组；组名是结构。条目含标题、日期、时长、摘要（有则显示）。
- 系列索引：系列名 + 篇数。系列页按日期，正文内 SeriesNav 视觉对齐刊头系统（字重、分割线、signal 链接）。
- 成果页沿用项目块，不改数据模型。

### 5.3 正文

页眉一行：`日期 · 约 N 分钟 · N 字`；有 series 则第二行仅系列名（可点回系列页）。其下才是标题。不是表格、不是后台字段墙。

代码块、引用、Mermaid 使用 signal/mist，不另起皮肤。阅读时长/字数逻辑保持现有 Layout 计算，只改呈现位置到页眉。

### 5.4 动效

仅一个入场：左栏与右栏错开升起（500–700ms，cubic-bezier ease-out）。列表不做逐条同款入场。按钮微抬、行悬停。`prefers-reduced-motion: reduce` 时全部 animation/transition 关闭。选区、`:focus-visible`、滚动条跟 signal。

## 6. 组件与数据

| 单元 | 职责 |
|---|---|
| `Layout.vue` | 顶栏字标槽、左刊头槽、正文目录、埋点、字数 |
| `Masthead.vue`（新建） | 按 `route.path` 切换完整 / 中 / 窄；窄模式渲染本页目录 |
| `LatestArticles` / `HomeProjects` / `ArticleList` / `Projects` / `Series*` | 内容组件，样式跟刊头 token |
| `custom.css` | token、栏宽、列表、文档排版、减动效 |
| `index.md` | 去掉 home hero frontmatter，只挂列表组件 |
| `config.mts` | `siteTitle: false`（自定义字标）；`search` 保持未配置 |

数据仍来自 `articles.data.ts`、`projects.data.ts`、`series.data.ts`。不新增 API。

空状态：文章列表为空时文案为「还没有文章」，不编造篇目。统计口令错误沿用「口令错误」；请求失败写明状态码含义。

## 7. 测试与验收

- `site` 下 `npm run build` 通过。
- 桌面：首页左刊头完整、右为文章流；点「阅读文章」「查看成果」到达正确路由。
- 文章列表、系列、成果、一篇正文、`/stats-view`：刊头密度符合第 4 节；正文无右侧 outline。
- 窄屏：刊头在内容之上，不出现水平溢出。
- 正文对比度 ≥4.5:1；键盘 Tab 可见焦点；系统减动效时无入场动画。
- 顶栏无搜索控件。
