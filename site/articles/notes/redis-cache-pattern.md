## 样本场景

访问量汇总接口：30 天趋势 + Top 页，查询频率低、数据量小。

## 决策

| 条件 | 样本选择 |
|------|----------|
| 单实例、QPS < 10 | MySQL 直查 + 简单索引 |
| 多实例 API | Redis 缓存日汇总 |
| 纯静态站 | 无缓存层 |

个人站当前样本：**不引入 Redis**，避免运维面扩大；文章里写清楚边界即可。
